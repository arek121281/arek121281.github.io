👶 Python dla początkujących

Podstawowe koncepty i składnia Pythona

📚 Podstawy składni

Python jest językiem wysokiego poziomu o czytelnej składni. Oto kluczowe elementy:

# Podstawowe typy danych liczba = 10 tekst = "Hello Python" lista = [1, 2, 3, 4, 5] krotka = (1, 2, 3) slownik = {"klucz": "wartość"} # Instrukcje warunkowe if liczba > 5: print("Liczba jest większa od 5") elif liczba == 5: print("Liczba równa 5") else: print("Liczba mniejsza od 5") # Pętle for i in range(5): print(i) while liczba > 0: print(liczba) liczba -= 1

📝 Zmienne

Dynamiczne typowanie, nazwy zmiennych muszą zaczynać się od litery lub podkreślenia.

🔢 Typy danych

int, float, str, bool, list, tuple, dict, set - podstawowe typy w Pythonie.

🔄 Pętle

for - iteracja po sekwencjach, while - wykonuj dopóki warunek prawdziwy.

⚡ Funkcje

def nazwa_funkcji(argumenty): - definiowanie funkcji z użyciem słowa kluczowego def.

🚀 Python średniozaawansowany

Funkcje, struktury danych i bardziej zaawansowane koncepty

⚡ List comprehensions i generatory

# List comprehension kwadraty = [x**2 for x in range(10)] parzyste = [x for x in range(20) if x % 2 == 0] # Generator expression generator = (x**2 for x in range(1000000)) # Leniwe obliczenia # Dict comprehension slownik = {x: x**2 for x in range(5)} # Wynik: {0: 0, 1: 1, 2: 4, 3: 9, 4: 16} # Zagnieżdżone list comprehensions macierz = [[i*j for j in range(3)] for i in range(3)] # Wynik: [[0, 0, 0], [0, 1, 2], [0, 2, 4]]

💡 List comprehension vs pętla for

List comprehensions są zwykle szybsze i bardziej czytelne dla prostych transformacji. Dla złożonych operacji lepiej używać tradycyjnych pętli.

🔧 Funkcje lambda i funkcje wyższego rzędu

# Funkcja lambda (anonimowa) dodaj = lambda x, y: x + y print(dodaj(5, 3)) # 8 # Użycie z map() liczby = [1, 2, 3, 4, 5] kwadraty = list(map(lambda x: x**2, liczby)) # Użycie z filter() parzyste = list(filter(lambda x: x % 2 == 0, liczby)) # Użycie z sorted() slowa = ["banan", "jabłko", "gruszka", "śliwka"] posortowane = sorted(slowa, key=lambda x: len(x)) # Funkcja wyższego rzędu def tworz_mnoznik(n): def mnoznik(x): return x * n return mnoznik podwoj = tworz_mnoznik(2) print(podwoj(5)) # 10

🏆 Python zaawansowany

Dekoratory, metaklasy, asynchroniczność i inne zaawansowane tematy

✨ Dekoratory

# Prosty dekorator def moj_dekorator(func): def wrapper(*args, **kwargs): print(f"Wywołuję funkcję: {func.__name__}") wynik = func(*args, **kwargs) print("Funkcja zakończona") return wynik return wrapper @moj_dekorator def przywitaj(imie): print(f"Witaj, {imie}!") # Użycie przywitaj("Anna") # Dekorator z argumentami def powtorz(n): def dekorator(func): def wrapper(*args, **kwargs): for _ in range(n): wynik = func(*args, **kwargs) return wynik return wrapper return dekorator @powtorz(3) def powiedz_czesc(): print("Cześć!") # Klasy jako dekoratory class Timer: def __init__(self, func): self.func = func def __call__(self, *args, **kwargs): import time start = time.time() wynik = self.func(*args, **kwargs) end = time.time() print(f"Czas wykonania: {end - start:.2f}s") return wynik

⚡ Asynchroniczność (async/await)

import asyncio import aiohttp async def pobierz_strony(urls): async with aiohttp.ClientSession() as session: tasks = [] for url in urls: task = asyncio.create_task(pobierz_strone(session, url)) tasks.append(task) strony = await asyncio.gather(*tasks) return strony async def pobierz_strone(session, url): async with session.get(url) as response: return await response.text() # Uruchomienie async def main(): urls = [ "https://python.org", "https://github.com", "https://stackoverflow.com" ] strony = await pobierz_strony(urls) print(f"Pobrano {len(stron)} stron") # Python 3.7+ asyncio.run(main())

🧠 Ważne koncepty Pythona

Kluczowe idee i zasady programowania w Pythonie

🐍 Zen Pythona

"Piękno jest lepsze niż brzydota. Proste jest lepsze niż złożone. Czytelność się liczy."

⚡ Duck Typing

"Jeśli chodzi jak kaczka i kwacze jak kaczka, to musi być kaczka" - typowanie przez zachowanie.

🔧 EAFP vs LBYL

Easier to Ask for Forgiveness than Permission vs Look Before You Leap - dwa style obsługi błędów.

📦 PEP 8

Oficjalny styl kodu Pythona - zasady formatowania, nazewnictwa i organizacji kodu.

🔄 GIL (Global Interpreter Lock)

Mechanizm w CPython, który pozwala tylko jednemu wątkowi na wykonanie kodu bajtowego Pythona naraz.

🎯 List vs Tuple

Listy są mutowalne (zmienne), krotki są niemutowalne (niezmienne). Wybór zależy od użycia.
