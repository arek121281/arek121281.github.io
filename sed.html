sed — Stream Editor

Kompletny przewodnik po sed — potężnym narzędziu do przetwarzania tekstu linia po linii w systemach Unix/Linux. Od podstaw do zaawansowanych wyrażeń regularnych.

🔍 Czym jest sed?

Stream Editor — edytor strumieniowy

📖 Definicja

sed (Stream EDitor) to narzędzie wiersza poleceń w Unix/Linux służące do przetwarzania i transformacji tekstu linia po linii. Sed czyta wejście (plik lub stdin), stosuje komendy edycji i wypisuje wynik na stdout — domyślnie nie modyfikuje pliku źródłowego.

💡 Kluczowa idea

Sed przetwarza tekst bez otwierania edytora — idealny do skryptów, automatyzacji, potoków (|) i jednolinijkowych transformacji. Nie wymaga interakcji użytkownika.

⚙️ Jak sed przetwarza tekst

# Cykl pracy sed (dla każdej linii wejścia): 1. READ — Wczytaj linię do pattern space (bufora roboczego) 2. EXECUTE — Zastosuj komendy sed do pattern space 3. PRINT — Wypisz zmodyfikowany pattern space na stdout 4. REPEAT — Wróć do kroku 1 dla następnej linii # Dwa bufory: Pattern Space — bufor roboczy (aktualna linia) Hold Space — bufor pomocniczy (do zaawansowanych operacji)

📐 Składnia sed

Format polecenia i flagi

📐 Ogólna składnia

# Podstawowa składnia: sed [opcje] '[adres]komenda' plik # Przykłady: sed 's/stary/nowy/' plik.txt # zamiana w pliku echo "hello" | sed 's/hello/world/' # z potoku sed -i 's/stary/nowy/g' plik.txt # edycja IN-PLACE (zmienia plik!) sed -n '5p' plik.txt # wypisz tylko linię 5 sed -e 's/a/A/' -e 's/b/B/' plik.txt # wiele komend sed -f komendy.sed plik.txt # komendy z pliku

🏳️ Flagi (opcje) sed

FlagaOpisPrzykład
-iIn-place — modyfikuje plik bezpośrednio (bez -i: stdout)sed -i 's/a/b/' plik
-i.bakIn-place z backupem (tworzy plik.bak)sed -i.bak 's/a/b/' plik
-nCiche — nie wypisuj automatycznie; wymaga jawnego psed -n '5p' plik
-eWiele komend — każda poprzedzona -esed -e 'cmd1' -e 'cmd2'
-fKomendy z pliku skryptowegosed -f skrypt.sed plik
-r / -EExtended regex (ERE) — +, ?, |, () bez backslashased -E 's/(foo|bar)/X/'
--posixTryb ścisłej zgodności POSIXsed --posix 's/a/b/'

🔄 s/ — Zamiana tekstu (substitution)

Najczęściej używana komenda sed

🔄 Składnia s/wzorzec/zamiana/flagi

# Format: sed 's/wzorzec/zamiana/flagi' # Flagi zamiany: g — Global — zamień WSZYSTKIE wystąpienia (nie tylko pierwsze) 1-9 — Zamień N-te wystąpienie p — Print — wypisz linię po zamianie (z -n) w — Write — zapisz zmodyfikowane linie do pliku i — Case-insensitive — ignoruj wielkość liter (GNU sed) I — Alias dla i (niektóre wersje)

📝 Przykłady zamiany

# === PODSTAWOWE === # Zamień pierwsze 'cat' na 'dog' w każdej linii: sed 's/cat/dog/' plik.txt # Zamień WSZYSTKIE 'cat' na 'dog' (flaga g): sed 's/cat/dog/g' plik.txt # Case-insensitive (Cat, CAT, cat → dog): sed 's/cat/dog/gi' plik.txt # Zamień tylko drugie wystąpienie w linii: sed 's/cat/dog/2' plik.txt # Edycja in-place z backupem: sed -i.bak 's/error/warning/g' log.txt # === SEPARATOR — nie musi być / === # Użyj | jako separatora (przydatne ze ścieżkami): sed 's|/usr/local|/opt|g' config.txt # Użyj # jako separatora: sed 's#http://#https://#g' urls.txt # === REGEX === # Usuń początkowe spacje: sed 's/^[ \t]*//' plik.txt # Usuń końcowe spacje: sed 's/[ \t]*$//' plik.txt # Zamień wiele spacji na jedną: sed 's/ */ /g' plik.txt # Dodaj prefix do każdej linii: sed 's/^/PREFIX: /' plik.txt # Dodaj suffix do każdej linii: sed 's/$/ #END/' plik.txt # === GRUPY I BACKREFERENCJE === # Zamień kolejność: "Kowalski Jan" → "Jan Kowalski": sed 's/\([^ ]*\) \([^ ]*\)/\2 \1/' names.txt # To samo z ERE (-E): sed -E 's/([^ ]+) ([^ ]+)/\2 \1/' names.txt # Otocz liczby nawiasami: 42 → [42]: sed -E 's/([0-9]+)/[\1]/g' data.txt # Duplikuj znalezione słowo: hello → hello hello: sed -E 's/(hello)/\1 \1/' # & — cały dopasowany tekst: sed 's/[0-9]*/[&]/g' # 42 → [42]

🗑️ d — Usuwanie linii

Kasowanie linii pasujących do wzorca

🗑️ Przykłady usuwania

# Usuń linię 3: sed '3d' plik.txt # Usuń linie 2-5: sed '2,5d' plik.txt # Usuń ostatnią linię: sed '$d' plik.txt # Usuń linie zawierające "error": sed '/error/d' plik.txt # Usuń puste linie: sed '/^$/d' plik.txt # Usuń linie zaczynające się od # (komentarze): sed '/^#/d' config.txt # Usuń linie NIE zawierające "important" (!): sed '/important/!d' plik.txt # Usuń od "START" do "END" (włącznie): sed '/START/,/END/d' plik.txt # Usuń od linii 10 do końca: sed '10,$d' plik.txt

📤 p — Drukowanie linii

Wypisywanie wybranych linii (z -n)

# Wypisz linię 5 (z -n aby nie duplikować): sed -n '5p' plik.txt # Wypisz linie 10-20: sed -n '10,20p' plik.txt # Wypisz linie zawierające "error": sed -n '/error/p' log.txt # Wypisz ostatnią linię: sed -n '$p' plik.txt # Wypisz od "BEGIN" do "END": sed -n '/BEGIN/,/END/p' plik.txt # Wypisz co drugą linię (kroku 2): sed -n '1~2p' plik.txt # nieparzyste sed -n '0~2p' plik.txt # parzyste # Wypisz numery linii (=): sed -n '/error/=' log.txt # numery linii z "error"

✏️ i / a / c — Wstawianie i zamiana linii

Dodawanie tekstu przed, po lub zamiast linii

# i\ — INSERT (wstaw PRZED linią): sed '3i\Nowa linia przed 3' plik.txt # a\ — APPEND (wstaw PO linii): sed '3a\Nowa linia po 3' plik.txt # c\ — CHANGE (zamień CAŁĄ linię): sed '3c\Zupełnie nowa linia 3' plik.txt # Wstaw nagłówek na początku pliku: sed '1i\# Nagłówek pliku' plik.txt # Dodaj stopkę na końcu pliku: sed '$a\# Koniec pliku' plik.txt # Wstaw linię po każdej linii z "SECTION": sed '/SECTION/a\---separator---' plik.txt # Zamień linie z "deprecated" na nowy tekst: sed '/deprecated/c\# REMOVED - deprecated feature' config.txt

🔬 Zaawansowane przykłady

# Zamień znaki (transliteracja) — jak tr: sed 'y/abcdefghij/ABCDEFGHIJ/' plik.txt # Odwróć kolejność linii (jak tac): sed -n '1!G;h;$p' plik.txt # Ponumeruj linie: sed '=' plik.txt | sed 'N;s/\n/\t/' # Usuń zduplikowane puste linie (jak cat -s): sed '/^$/N;/^\n$/d' plik.txt # Zamień wieloliniowy blok: sed '/START/{N;s/START\nOLD/START\nNEW/}' plik.txt # Wypisz linie między dwoma wzorcami (bez nich): sed -n '/BEGIN/,/END/{/BEGIN/d;/END/d;p}' # Zamień newline na spację (join lines): sed ':a;N;$!ba;s/\n/ /g' plik.txt # Zamień tylko w liniach zawierających "config": sed '/config/s/false/true/g' settings.txt # Wiele komend na jednym adresie { }: sed '/error/{s/error/ERROR/;s/$/ !!!/}' log.txt # Przeczytaj plik i wstaw po wzorcu: sed '/INSERT_HERE/r fragment.txt' main.txt
