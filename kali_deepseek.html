🛡️ Kali Linux - Podstawy

Profesjonalna dystrybucja do testów penetracyjnych i bezpieczeństwa

⚙️ Czym jest Kali Linux?

Kali Linux to zaawansowana dystrybucja Linuksa stworzona przez Offensive Security, przeznaczona do testów penetracyjnych, audytów bezpieczeństwa i badań w zakresie cyberbezpieczeństwa.

📦 Key Features:

  • 600+ specjalistycznych narzędzi - preinstalowane i skonfigurowane
  • Wielojęzyczne wsparcie - pełne tłumaczenia
  • Custom kernel - z patchemi dla iniekcji pakietów
  • Developerskie środowisko - VSCode, compilery, debuggers
  • ARM support - dla Raspberry Pi, IoT devices

⚠️ Legalne Użycie

Kali Linux powinien być używany TYLKO na systemach, na które masz pisemne pozwolenie do testów. Nieautoryzowane testy penetracyjne są nielegalne w większości krajów.

🔍 Faza 1: Reconnaissance

Zbieranie informacji i rozpoznanie celu

Network Scanner

🗺️ Nmap

Zaawansowany skaner sieciowy do discovery i audytu bezpieczeństwa.

root@kali:~# nmap -sS -sV -O -p- 192.168.1.1
# Stealth SYN scan + version detection + OS fingerprinting
-sS -sV -O -p- -A -T4
root@kali:~# nmap --script vuln 192.168.1.0/24
# Automatyczne skanowanie podatności w całej sieci
OSINT Framework

🕵️ Recon-ng

Kompletne środowisko OSINT (Open Source Intelligence) z modułami.

root@kali:~# recon-ng
[recon-ng][default] > modules load recon/domains-hosts/brute_hosts
[recon-ng][default][brute_hosts] > set SOURCE example.com
[recon-ng][default][brute_hosts] > run
workspaces modules database reporting
Email/Subdomain

📧 theHarvester

Zbieranie emaili, subdomen, hostów z publicznych źródeł.

root@kali:~# theHarvester -d example.com -b all -l 500
# Zbieranie z wszystkich źródeł, limit 500 wyników
-d -b -l -f -g

# Zbieranie z Google, Bing, LinkedIn z weryfikacją DNS

🎯 Zaawansowane Techniki Recon

🌐 Passive Reconnaissance (Pasywne rozpoznanie)

Zbieranie informacji bez bezpośredniej interakcji z celem:

  • WHOIS lookup: whois example.com
  • DNS enumeration: dnsrecon -d example.com
  • Google Dorks: site:example.com filetype:pdf
  • Shodan: shodan search apache country:PL
  • Wayback Machine: waybackurls example.com

🎪 Active Reconnaissance (Aktywne rozpoznanie)

Bezpośrednia interakcja z systemami celu:

root@kali:~# nmap -sn 192.168.1.0/24
# Ping sweep całej sieci (host discovery)

root@kali:~# masscan -p1-65535 10.0.0.0/8 --rate=1000
# Szybkie skanowanie portów dużej sieci

root@kali:~# sublist3r -d example.com -o subdomains.txt
# Enumeracja subdomen

🎪 Zaawansowane Techniki Skanowania

🎯 Port Scanning Techniques

  • TCP SYN Scan (-sS): Half-open scanning, stealth
  • TCP Connect Scan (-sT): Full TCP connection
  • UDP Scan (-sU): UDP port discovery
  • ACK Scan (-sA): Bypass firewall rules
  • FIN Scan (-sF): FIN flag scanning
  • NULL Scan (-sN): No flags set
  • XMAS Scan (-sX): FIN, PSH, URG flags

🧩 Service & Version Detection

root@kali:~# nmap -sV --version-intensity 9 192.168.1.1
# Aggressive version detection (0-9 scale)

root@kali:~# nmap -sC -sV -oA full_scan 192.168.1.1
# Script scan + version + output all formats

root@kali:~# nmap --script=http-enum 192.168.1.100
# HTTP enumeration script

🎪 Zaawansowane Techniki Wireless

🔓 WPA/WPA2 Cracking Workflow

  1. Monitor Mode: airmon-ng start wlan0
  2. Network Discovery: airodump-ng wlan0mon
  3. Capture Handshake: airodump-ng -c CHANNEL --bssid BSSID -w capture wlan0mon
  4. Deauth Attack: aireplay-ng -0 10 -a BSSID -c CLIENT wlan0mon
  5. Crack Password: aircrack-ng -w rockyou.txt capture-01.cap
  6. Hashcat (GPU): hashcat -m 2500 capture.hccapx rockyou.txt
