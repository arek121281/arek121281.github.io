🧪 Podstawy

Czym jest Flask?

Flask to lekki framework webowy Pythona (micro-framework). Nie narzuca ORM, formularzy ani narzędzi — dodajesz to, czego potrzebujesz. Stworzony przez Armina Ronachera (Pallets Projects).

🧪

Micro-framework

Minimalne jądro — routing, request/response, Jinja2. Resztę wybierasz sam (ORM, auth, forms).

🔧

WSGI + Werkzeug

Oparty na Werkzeug (WSGI toolkit) i Jinja2 (template engine). WSGI = interfejs między serwerem a aplikacją.

📦

Ekosystem rozszerzeń

Flask-SQLAlchemy, Flask-Login, Flask-WTF, Flask-RESTful, Flask-Migrate, Flask-Mail, Flask-CORS...

📄 Jinja2

Szablony Jinja2

Jinja2 Template
{# Komentarz Jinja2 #} {# Dziedziczenie szablonów #} {% extends "base.html" %} {% block content %} <h1>{{ title }}</h1> {# Zmienna #} {% for item in items %} {# Pętla #} <p>{{ item.name | capitalize }}</p> {# Filtr #} {% endfor %} {% if user.is_admin %} {# Warunek #} <p>Panel admina</p> {% elif user.is_logged %} <p>Witaj {{ user.name }}</p> {% else %} <p>Zaloguj się</p> {% endif %} {{ url_for('static', filename='style.css') }} {% endblock %}

💡 Autoescaping

Jinja2 automatycznie escapuje HTML w {{ }} — chroni przed XSS. Aby wyłączyć: {{ content | safe }} — używaj ostrożnie!

❓ FAQ

Najczęstsze pytania

Flask vs Django — kiedy który?+

Flask — gdy chcesz pełną kontrolę, mały projekt, REST API, mikroserwisy, nauka. Django — gdy potrzebujesz „batteries included" (admin, ORM, auth, forms), duży projekt, CMS. Flask = elastyczność, Django = produktywność.

Co to jest application factory pattern?+

Zamiast globalnego app = Flask(__name__), tworzysz funkcję create_app(config), która zwraca instancję aplikacji. Umożliwia: różne konfiguracje (dev/test/prod), testowanie, unikanie circular imports. Rekomendowany wzorzec dla większych projektów.

Jak deployować Flask w produkcji?+

Nigdy nie używaj app.run() w produkcji! Użyj serwera WSGI: Gunicorn (Linux) lub Waitress (Windows). Przed nim reverse proxy: Nginx. Stack: Nginx → Gunicorn → Flask. Lub: Docker + cloud (AWS, GCP, Heroku).

Co to jest Blueprint?+

Blueprint to „mini-aplikacja" Flask — moduł z własnymi routes, templates, static files. Umożliwia podział dużej aplikacji na logiczne części: auth_bp, api_bp, admin_bp. Rejestrowany: app.register_blueprint(auth_bp, url_prefix="/auth").
